# GameNest Shop
Complete long-form responsive storefront.

Files:
- index.html
- style.css
- script.js
- assets/vbucks.png
- assets/crew.png
- assets/favicon.png

Upload the files and keep the assets folder exactly as shown.
Before using the WhatsApp order button, edit WA_NUMBER in script.js and replace the placeholder with your real international number.

The site is an independent storefront and is not affiliated with Epic Games.
