# GameNest Shop

Responsive black-and-white GameNest storefront for GitHub Pages.

## GitHub Pages upload structure

Upload the CONTENTS of this folder to the repository root:

    index.html
    style.css
    script.js
    assets/
      gamenest-logo.png

Do not move `gamenest-logo.png` out of `assets`.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The exact GameNest logo supplied by the owner is included at:
`assets/gamenest-logo.png`
