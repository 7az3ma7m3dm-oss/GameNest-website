# GameNest Shop — GitHub Pages Ready

This version avoids broken logo paths.

Upload these files directly to the ROOT of your repository:

- `index.html`
- `style.css`
- `script.js`
- `gamenest-logo.png`
- `README.md`

The logo is also embedded directly inside `index.html`, so the website does NOT depend on an `assets/` folder.

GitHub Pages:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.
