# GameNest Shop

Responsive black-and-white Fortnite storefront designed for phones, tablets, laptops and desktop PCs.

## Upload to GitHub Pages
Upload these items to the repository root:
- index.html
- style.css
- script.js
- assets/gamenest-logo.svg

Then GitHub Pages → Deploy from branch → main → /(root).

The layout uses responsive breakpoints so it does not become a phone-only design on larger screens.


Logo: `assets/gamenest-logo.png` is the uploaded GameNest logo and is used in the site and browser tab icon.
