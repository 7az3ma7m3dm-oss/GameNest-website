# GameNest Shop

A complete responsive black-and-white GameNest storefront.

## Files
- `index.html` — complete storefront
- `style.css` — all styling, responsive layouts and custom desktop cursor
- `script.js` — custom cursor and small interactions
- `favicon.png` — GameNest favicon made from the uploaded logo
- `assets/gamenest-logo.png` — the uploaded GameNest logo used inside the website

## GitHub Pages
Upload the files exactly as they are, keeping the `assets` folder.

The important structure is:

GameNest-Shop/
├── index.html
├── style.css
├── script.js
├── favicon.png
└── assets/
    └── gamenest-logo.png

Do not move `gamenest-logo.png` out of `assets`, otherwise the logo paths will break.

The website is responsive for phones, tablets, laptops and desktop PCs.
