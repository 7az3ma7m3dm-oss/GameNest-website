# GameNest Shop

Upload ALL of these files directly to the ROOT of your GitHub repository:

- index.html
- style.css
- script.js
- vbucks.png
- crew.png
- favicon.png
- favicon.ico

No `assets` folder is required.

The V-Bucks image is used in the V-Bucks store section.
The Crew image is used in the Fortnite Crew section.
The favicon uses the supplied GameNest logo.
